# 卡片交互优化验收基线

2026-10-24 的[左侧简化验收基线](sidebar-simplification-baseline.md)更新了显隐控件、双行内容分工、说明文字和工具入口；下文保留历史决议，领域行为与交互回归继续适用。

规格来源：2026-10-19 对话中用户确认“落地所有 UI 优化建议”。审查固定点：`737b8af`。

## 必须交付

1. **紧凑列表**：每卡两行：首行是拖拽入口、名称、解析状态和删除；次行是格式/行数等摘要与“参与分析”。去掉重复的表格图标与“编辑中”标签，不重复渲染原文；列表限高、独立滚动。1440×900 桌面视口下六张卡片不把解析按钮挤出首屏；原文和解析操作归于明确的当前编辑区。
2. **独立状态**：浅色背景、细边框、`aria-current` 与原文区当前编辑名称表达编辑对象，原生“参与分析”复选框独立表达表池成员；键盘焦点保留单独的可见描边。退出分析不使用删除线或整卡淡化，仍可浏览和编辑。单卡、多卡、当前卡退出分析及零参与卡片均须正确。
3. **粘贴说明**：显示当前编辑卡名；普通粘贴按光标/选区处理，全选后粘贴替换整卡。大段粘贴/只读原文预览明确提示整卡替换，完整原文继续保留。新增卡片自动选中并聚焦原文框。
4. **键盘与焦点**：↑↓、Home/End 移动列表焦点但不改变编辑对象；Enter/Space 选中，F2/双击原位改名，Enter/blur 保存、Esc 取消。改名和参与开关刷新不丢焦点、不打断正在输入的名称；点击删除按钮或按 Delete 直接删除卡片/页签（包括最后一个），不弹二次确认。删除后的空状态、相邻项选择、焦点行为和后台数据释放保留；工作区恢复、清除本地数据等其他操作的确认不变。
5. **一致命名**：新默认卡片统一为工作区内唯一的“数据段 N”，工程继续为“Analysis N”；不批量改写历史名称。工程和卡片名称分别保证唯一。新的默认主卡使用显式导出命名策略保留工程名前缀；用户改卡名后改用卡名，复制和旧备份保持卡名语义，排序不改变文件前缀。
6. **解析摘要**：卡片区分空、待解析、已解析、待确认、失败；成功显示格式和完整行数，而不是当前页行数。只缓存修订/策略匹配的少量摘要，不持久化结果计数或复制完整数据；惰性解析的卡片同样更新摘要。
7. **范围统计**：右侧标题属于工程表池，不属于当前编辑卡片；显示参与/总卡片数，以及当前筛选结果的表数、完整行数（包含启用的 JOIN 结果），明确不是当前页计数。零参与来源不残留旧表。
   - 显隐回归：已解析首来源隐藏后，异结构来源的限定名仍保持；需等待旧来源表确实退出 DOM 后再断言，不能在异步更新前检查旧标题而掩盖错误。
8. **排序入口**：拖拽手柄和 Alt+↑↓ 均可调整卡片顺序，提示该顺序决定拼接顺序；保持编辑对象、原文、记录数和焦点，不去重、不自动按名字排序。重命名、来源修订和卡片修正需要使相关查询缓存失效。

- `tests/unit/store.test.js`：默认/历史/自定义名称、唯一性、导出命名策略及备份兼容。
- `tests/unit/card-metadata.test.js`、`source-controller.test.js`：Window/Worker 行数、策略/原文失效和状态文案。
- `tests/unit/query-service.test.js`、`worker-runtime.test.js`：表池缓存和限定名刷新。
- `tests/integration/card-ui.test.js`、`card-worker-metadata.test.js`：真实模块协作、范围和惰性元数据传输。
- `e2e/card-interaction.e2e.js`：Chromium 真实布局、键盘、改名、焦点、剪贴板、状态、显隐、排序和导出读回；已有多卡、大数据、删除恢复流程继续回归。
- Termux 使用桌面 Firefox/WebDriver 另行验证 `file://`、亮/暗主题和窄屏回退；不能替代 CI Chromium 结果。

## 解析状态可发现性补充

- 状态灯与不可压缩的文字标记配对：空卡片、待解析、解析中、解析完成、待确认、解析失败、未识别表格。成功摘要继续显示格式和完整行数；“未识别”不伪装成有候选待确认。
- 用现有中性、棕色、绿色、琥珀色、红色语义区分状态，并提供空心、虚线、旋转、对勾、感叹号与叉号等图形辅助；不只依赖颜色。空卡片、待解析、解析中、解析完成采用无可见边框/底色的图标＋文字；待确认、解析失败、未识别表格保留浅色底与细边框。状态在首行始终完整，优先截断长名称或次行摘要。保留明暗主题、紧凑双行、减少动态和读屏状态反馈。
- 待确认不能显示成首次使用或筛选为空：右侧明确解释确认后才会出表、原文已保留，并提供进入现有解析详情的按钮。侧栏“详情”同步改为醒目的“确认候选”。没有候选时改为查看详情/手动选择格式的说明。
- 其他卡片已解析的表格保留在提示下方；非当前参与卡片的待确认信息也可定位到对应卡片。已退出分析或原文/策略修订不匹配的其他卡片不产生过期提示。
- 确认完成后提示消失；从右侧入口选择候选后，焦点落到稳定的“立即解析”按钮，关闭详情而未选择时回到原入口。不改变候选判断、临时确认生命周期、原文或持久化结构。
- 回归位置：`tests/integration/parse-feedback.test.js`、`e2e/parse-status.e2e.js` 与 `e2e/card-simplicity.e2e.js` 覆盖两行信息分工、简化装饰、正常/异常状态层级、格式/区域/表头三类确认、入口与恢复、保留其他结果和长名称在明暗/窄屏下的可见性。
