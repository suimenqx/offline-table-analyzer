# 卡片交互优化验收基线

规格来源：2026-10-19 对话中用户确认“落地所有 UI 优化建议”。审查固定点：`737b8af`。

## 必须交付

1. **紧凑列表**：每卡两行，不重复渲染原文；列表限高、独立滚动。1440×900 桌面视口下六张卡片不把解析按钮挤出首屏；原文和解析操作归于明确的当前编辑区。
2. **独立状态**：“编辑中”与原生“参与分析”复选框分别表达编辑对象、表池成员；退出分析不使用删除线或整卡淡化，仍可浏览和编辑。单卡、多卡、当前卡退出分析及零参与卡片均须正确。
3. **粘贴说明**：显示当前编辑卡名；普通粘贴按光标/选区处理，全选后粘贴替换整卡。大段粘贴/只读原文预览明确提示整卡替换，完整原文继续保留。新增卡片自动选中并聚焦原文框。
4. **键盘与焦点**：↑↓、Home/End 移动列表焦点但不改变编辑对象；Enter/Space 选中，F2/双击原位改名，Enter/blur 保存、Esc 取消。改名和参与开关刷新不丢焦点、不打断正在输入的名称；删除后的空状态和焦点行为保留。
5. **一致命名**：新默认卡片统一为工作区内唯一的“数据段 N”，工程继续为“Analysis N”；不批量改写历史名称。工程和卡片名称分别保证唯一。新的默认主卡使用显式导出命名策略保留工程名前缀；用户改卡名后改用卡名，复制和旧备份保持卡名语义，排序不改变文件前缀。
6. **解析摘要**：卡片区分空、待解析、已解析、待确认、失败；成功显示格式和完整行数，而不是当前页行数。只缓存修订/策略匹配的少量摘要，不持久化结果计数或复制完整数据；惰性解析的卡片同样更新摘要。
7. **范围统计**：右侧标题属于工程表池，不属于当前编辑卡片；显示参与/总卡片数，以及当前筛选结果的表数、完整行数（包含启用的 JOIN 结果），明确不是当前页计数。零参与来源不残留旧表。
   - 显隐回归：已解析首来源隐藏后，异结构来源的限定名仍保持；需等待旧来源表确实退出 DOM 后再断言，不能在异步更新前检查旧标题而掩盖错误。
8. **排序入口**：拖拽手柄和 Alt+↑↓ 均可调整卡片顺序，提示该顺序决定拼接顺序；保持编辑对象、原文、记录数和焦点，不去重、不自动按名字排序。重命名、来源修订和卡片修正需要使相关查询缓存失效。

## 验证位置

- `tests/unit/store.test.js`：默认/历史/自定义名称、唯一性、导出命名策略及备份兼容。
- `tests/unit/card-metadata.test.js`、`source-controller.test.js`：Window/Worker 行数、策略/原文失效和状态文案。
- `tests/unit/query-service.test.js`、`worker-runtime.test.js`：表池缓存和限定名刷新。
- `tests/integration/card-ui.test.js`、`card-worker-metadata.test.js`：真实模块协作、范围和惰性元数据传输。
- `e2e/card-interaction.e2e.js`：Chromium 真实布局、键盘、改名、焦点、剪贴板、状态、显隐、排序和导出读回；已有多卡、大数据、删除恢复流程继续回归。
- Termux 使用桌面 Firefox/WebDriver 另行验证 `file://`、亮/暗主题和窄屏回退；不能替代 CI Chromium 结果。

## 不在本轮范围

批量管理、去重、卡片间 JOIN 配置、大原文编辑器、联网服务、运行时依赖和模块加载策略改变。
