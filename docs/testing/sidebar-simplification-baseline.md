## 交互与数据约束

- 切换眼睛不改变编辑对象，不删除原文、不释放解析数据、不触发重解析；表池、过滤、JOIN 和 Excel 继续按可见清单计算。
- 卡片 DOM 继续按 id 复用；改名、删除、方向键、排序、减少动态和长名称行为保持。首行名称/操作、次行状态/摘要，卡片小于 90px，列表限高不超过 230px，1440×900 六卡仍能看到解析按钮。
- 原生 details/summary 与普通按钮支持 Enter/Space、Tab、Escape、外部点击和焦点离开关闭。执行工具前关闭菜单并将焦点置于可见入口，避免关闭诊断后返回隐藏菜单项。设置复选框操作不关闭菜单。
- 无新增持久化字段、迁移、模块或运行时依赖；现有工作区与备份兼容。新增 `ui:spreadsheetSafe` 命令复用既有 Store setter，不允许 UI 直接写状态。
- 解析警告、截断、候选确认、保存/导出/导入失败继续可见；信息级诊断不作为成功界面的常驻警告。
