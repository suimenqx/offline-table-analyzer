# 卡片精密交互落地方案与验收基线

固定点：`b226eff`。范围来自用户确认：卡片更精致、更有交互感，但颜色必须兼容现有经典印象，不能借科技感改换品牌风格。

## 视觉约束

- 不改全局 token、字体、顶栏、结果表与主题切换。暖白、棕色主操作、青绿选择/参与、现有石墨灰暗色主题继续保留；不引入电蓝、紫色、霓虹、玻璃模糊或持续装饰动画。
- 仅精修数据卡片：紧凑双行、细边缘与轻微内层高光、拖拽/删除沿用既有线性 SVG 语言、清晰标题、等宽数据摘要和原生参与复选框。常用操作始终可见；不恢复原文缩略图。
- 后续轻量化范围（用户确认前三项）：去掉统一表格图标和重复“编辑中”标签；首行名称/状态/删除，次行摘要/参与。编辑对象通过浅底、细边框、`aria-current` 和原文区名称表达，键盘焦点仍独立可见。不再叠加选中侧线；普通解析状态不绘制底色/边框，待确认/失败/未识别保留提示底色。不改变名称、解析与参与语义、删除行为、拖拽和右侧确认流程。
- 选中、焦点、参与及解析状态分别表达；退出分析不删除线、不整体淡化。卡片仍小于 90px，列表限高不超过 230px，1440×900 六卡时解析按钮仍在首屏。

## 交互与动效

1. 选中、悬停、参与与改名的反馈短而克制，不改变卡片尺寸，不做悬浮放大或循环流光。
2. 拖拽是主要动效：保留原生拖拽影像与手柄，邻卡预览让位、落点清楚；预览只改瞬时视觉位置，落下才 dispatch `card:reorder`。Escape、拖出列表取消、工程/卡片变化均清理预览，不改变编辑对象或原文。
3. 拖拽与 Alt+↑↓ 共用排序语义；排序后保持焦点。运动主要使用 transform 与原生 Web Animations，约 180ms，允许被后续操作中断；无动画 API 时仍正常排序。
4. `prefers-reduced-motion` 时不做位移补间或旋转，保留文字、描边与落点反馈；不因减少动态而失去操作能力。
5. 仅在真实后台解析在途时显示“解析中”，完成、失败、取消后恢复相应状态。旧作业结束不能清掉新作业状态，来源修订变化后不沿用旧忙碌标记。不伪造百分比、不把筛选/JOIN 当作解析。

## 所有权与实施次序

- SourceController 继续拥有卡片 DOM、焦点、拖拽几何/预览、短生命周期动效和忙碌标记。App 只通过公开接口通知真实解析开始/结束；Store 仍唯一拥有持久化顺序、选择、参与和原文。
- 不增模块、运行时依赖、持久化字段或迁移；不改模块加载和单 HTML 发布模式。
- 先以公开状态接口锁定忙碌生命周期，再接真实解析集成；随后完成卡片样式与拖拽，补浏览器色板、预览取消、焦点、减少动态回归。
- Node 回归、发布/架构校验、本地桌面 Firefox 与 CI Chromium 分别记录。视觉按明/暗/紧凑桌面/窄屏进行一轮批量检查，必要时一次集中修正并确认。

## 不在本轮范围

规则的工程/卡片归属、拼接单元格修正边界、结果区分页键盘改造、导出语义、批量管理、大原文编辑及图表能力。本轮通过不代表这些既有独立问题已经修复。
