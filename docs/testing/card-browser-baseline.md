# 卡片浏览与删除恢复验收基线

来源：2026-10-25 用户授权实施左侧卡片栏的全部七项建议。延续经典明暗配色、双行卡片、眼睛显隐和桌面浏览器定位；默认列表仍不超过 230px，显式展开是临时浏览状态。

## 行为

1. 选中卡片使用棕色细条、边框和浅背景；原文标题使用对应棕色标识。显隐、异常状态和键盘焦点继续独立。
2. 四张起提供展开/收起，展开高度上限 `min(480px, 55vh)`；选择卡片自动收起。紧凑态保留 220px 列表上限，解析按钮在桌面首屏内。
3. 待确认、解析失败和未识别标记有原生按钮入口，支持鼠标与 Enter/Space。可直接定位其他或隐藏卡片；等待当前解析完成，不展示切换卡片/来源/策略后的过期详情。关闭详情恢复焦点。
4. 眼睛保持清晰，拖拽和删除图标降低默认视觉权重，悬停/键盘进入卡片后增强；操作位置与卡片尺寸固定。强制色模式保持图标可见。
5. 拖动时可见“移至第 N 位”与拼接顺序含义；落下才写入 Store，Escape/取消清除提示并保留原顺序。键盘排序完成同样显示位置反馈。
6. 八张起出现名称搜索，忽略大小写和查询首尾空白；显示匹配数与无结果状态。搜索只隐藏列表项，保留完整表池、显隐、JOIN、导出和原始顺序；清除后可以排序。匹配项具有键盘入口，方向键跳过不匹配项；新增卡片清除搜索，切换工程重置搜索和展开状态。搜索框兼容明暗主题，空查询不显示清除按钮。
7. 删除立即生效，不二次确认。最近一张删除保留 15 秒的会话撤销：完整原文、来源修订、修正覆盖层、解析策略、显隐和原位置均恢复；重新选中并解析，原 Worker 数据集仍在删除时释放。最后一张卡片同样可撤销；同名冲突使用既有唯一命名策略。新删除替换旧撤销，过期/删除所属工程/清除本地数据/成功导入工作区清除快照；失败导入保留。恢复超过既有原文总预算时明确失败，其他数据及可恢复快照保留。撤销不进入备份和持久化 schema。

## 回归覆盖

- `tests/unit/card-removal.test.js`：命令恢复、完整字段与原位置、末卡、唯一名称、所属工程、单槽、过期、导入和清除边界、无新增持久化字段。
- `tests/integration/card-ui.test.js`：搜索不改状态/结果范围、匹配项键盘入口、临时展开、跨工程重置、诊断请求失效、删除撤销后真实解析恢复修正。
- `e2e/card-browser.e2e.js`：生成发布文件中的展开/选中、明暗标识、搜索与键盘、异常直达与返回焦点、恢复原文/显隐/修正、超时和可见拖拽落点。既有卡片、解析确认、JOIN 和 XLSX 回归继续适用。

## 本地验证

- Node：513 项通过；发布与架构验证通过，仍为 46 模块、schema 22、单 HTML、零运行时依赖。
- Firefox 158.0.1 + WebDriver 从 `file://` 验证删除恢复的原顺序/显隐/原文/修正与 Worker 结果、当前失败及其他卡片候选直达/焦点、搜索不改持久化/分析范围、键盘匹配项导航、展开和选中收起；未捕获页面错误。
- 1440/1024/680px：卡片高 66px、紧凑列表高 220px、解析按钮底部 529px（可用视口高 915px），均无页面横向溢出；明暗、展开与窄屏截图检查。
- 本机 `npm run test:e2e` 因 Playwright 不支持 Android 而无法启动；Ubuntu CI 的 Chromium 结果单独记录。
