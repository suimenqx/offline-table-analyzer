# 决定用户如何审查和修正提取结果

Type: prototype
Status: open
Blocked by: 01, 02, 04, 05

## Question

在目标结果、可信标准和技术可能性清楚后，做一个低保真交互草案，检验用户如何看见原文到结果的对应、遗漏内容和多个合理解释，并用最少的操作修正提取结果。

## Comments

- 用户已明确授权先做对照评估。初步[单文件交互原型](../evaluation/prototype.html)已作为探针完成；它展示原文定位、未解释内容、表头/表范围/单元格纠错。目标和可信标准尚未定案，本票仍待正式用户复核。
- [保留样本失败归因](../evaluation/failure-analysis.md)显示原型分别缺少跨行引号记录、HTML 结构表示和定宽列推断；这些是可追溯结果契约之外的发现算法问题。
